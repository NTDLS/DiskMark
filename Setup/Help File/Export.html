Exporting Results

Once a test has produced results you can keep them with Export... or Copy Results on the main window. Cancelled or failed tests can be exported too; the report notes that the results are partial.

What is included:
  • Drive - drive letter and type, volume label, file system, device vendor and model, bus (NVMe, SATA, USB, ...), SSD or HDD, capacity and free space at the start of the test. Details the drive does not report are shown as Unknown.
  • Configuration - block size, test file size, duration per phase and the write cache setting.
  • Results - for writes and reads: average, minimum, maximum and last throughput (MB/s), IOPS, average latency, number of samples and disk time.
  • The date and time the test started and its outcome.
Export...
Opens a Save dialog. Choose Text report (.txt) for a readable summary, or CSV spreadsheet (.csv) for use in Excel or other tools. The CSV has a header row and one row per phase (Write, Read) with the drive and configuration repeated on each row, so exports from several tests or machines can be combined into one sheet. The suggested file name contains the drive letter and the date and time.

Copy Results
Places the same text report on the clipboard.
