Settings Dialog

The settings dialog appears when DiskMark starts and whenever you press Run. It sets the parameters of the benchmark. Your choices are remembered for next time.

Disk drive:
The drive to benchmark. Fixed disks, removable media, network drives and RAM disks are listed; CD-ROM drives are not. The test file is created in the root of the drive (or in a DiskMark-Temp folder if the root is not writable) and is deleted when the test ends.

Block size:
How much data is read or written with each I/O request. Small blocks (4 KB) emphasize IOPS and latency; large blocks (1 MB and up) emphasize sequential throughput. The value is rounded up to a multiple of the drive's sector size, and may not exceed 1 GB or one quarter of your physical RAM.

Test file size:
The size of the temporary file used for the test. DiskMark does sequential I/O through the file and wraps back to the start when it reaches the end, so the file can be much smaller than the amount of data moved during the test. The file must fit in the drive's free space and hold at least one block. Use a size larger than the drive's own cache (for example 1 GB or more) for the most honest results.

Duration (sec):
How long the write test runs, and then how long the read test runs. The default is 30, so a default test takes about a minute. Throughput is sampled once per second; longer tests give a better picture of sustained performance, including any slowdown when a drive's fast cache fills.

Allow OS write caching:
Unchecked (the default), writes bypass the Windows file cache and are written through to the device, so you measure the drive itself. When checked, Windows may buffer writes, but DiskMark flushes the file at the end of every sample and includes the flush in the timing, so the result is still the rate at which data reaches the disk. Reads always bypass the Windows cache.

Expressions:
The block size, test file size and duration accept simple expressions such as 64 * 1024 or 1024 * 1024 * 1024.

Buttons:
Start begins the test. Cancel closes the dialog without testing. Help opens this help file and About shows version information.
