Known Bugs

DiskMark would not of been released if there were any "known" bugs.

Some drives and controllers have their own caches that no program can bypass, which can make short tests appear faster than the drive's sustained speed. Use a longer duration and a larger test file for sustained figures. See How Results Are Measured.

If you have found error in DiskMark please see Reporting Bugs under the "Contact" section in this help file.
