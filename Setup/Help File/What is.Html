What is DiskMark?

DiskMark is a small utility that benchmarks the performance of your disks and drives. It measures sequential write and read throughput (MB/s), IOPS and latency, and graphs the results second by second. You choose the drive, block size, test file size and duration, and can export the results together with the drive details.

See the Settings Dialog and Main Window topics to get started, or How Results Are Measured to learn how the numbers are produced.
