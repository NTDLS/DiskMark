Requirements

Minimum/Recommended Specs.

Resource Requirement
Operating system Windows 10 or later (developed and tested on Windows 11)
Disk space Free space on the tested drive at least equal to the test file size (1 GB by default)
RAM Enough for the block size you choose (limited to one quarter of physical RAM)
Permissions A standard user account is sufficient. DiskMark uses a DiskMark-Temp folder when the drive root is not writable.
