Main Window

The main window summarizes the test you selected and shows the results as they arrive. The write test runs first, followed by the read test.

Test Configuration:
The drive, write cache setting, block size, test file size and the duration of each phase.

Write Performance / Read Performance:
Each phase has its own panel. The large figure is the average throughput in MB/s (1 MB = 1,048,576 bytes), calculated as total bytes moved divided by total time. Below it are:
  • Last - throughput of the most recent one-second sample.
  • Min / Max - the slowest and fastest one-second samples seen so far.
  • IOPS - I/O operations per second (one operation is one block).
  • Latency - the average time to complete one block.
  • Disk time - the time actually spent performing timed I/O.
Graphs:
Each graph plots one-second samples over the length of the test and labels its vertical scale in MB/s. The lines are Last (amber), Avg (gray), Max (green) and Min (red); the current value of each is printed above the plot.

Progress bar and status:
Shows how much of the whole test (write and read) has completed and what the test is currently doing.

Buttons:
  • Run / Cancel - opens the settings dialog and starts a test; while a test is running the button cancels it.
  • Copy Results - copies a text report to the clipboard.
  • Export... - saves the results to a file. See Exporting Results.
  • Help and About - open this help file and version information.
  • Always on top - keeps the window above other windows.
Copy Results and Export are available once a test has produced results, including a cancelled one.
