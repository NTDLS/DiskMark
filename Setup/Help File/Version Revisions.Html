Version Revisions

  • DiskMark (2.0.0.0)
    • (1) Tests are now time-based: set a duration (default 30 seconds) for the write test and the read test, sampled once per second. Replaces "IOs" and "Iterations".
    • (2) New "Test file size" setting. The old "Chunk Size" is now "Block size".
    • (3) More accurate and meaningful results: reads always bypass the file cache, cached writes are flushed inside the timed region, I/O buffers are sector aligned and filled with incompressible data, and the average is total bytes over total time.
    • (4) Added IOPS, latency and per-second minimum, maximum and last throughput.
    • (5) Added Export (text or CSV) with drive details, configuration and results, and a Copy Results button.
    • (6) Redesigned user interface with large headline figures, improved graphs, status line, DPI awareness and About buttons.
    • (7) Works without administrator rights, and settings are now saved per user.
    • (8) Fixed several bugs including settings that were never saved, input errors that went unreported, and a free-space check that could overflow.
  • DiskMark (1.0.0.0)
    • (1) Initial Beta Release.
